# Edgebook

Trading journal postavený na Next.js, Reactu a Tailwind CSS. První UI milník obsahuje dashboard, souhrnné metriky, tabulku obchodů a formulář pro přidání obchodu do aktuální relace.

## Spuštění

```bash
npm install
npm run dev
```

Otevři `http://localhost:3000`.

## Struktura

```text
src/
  app/                    Next.js routy a globální styly
  components/dashboard/   dashboardové UI komponenty
  lib/                    malé sdílené utility
```
